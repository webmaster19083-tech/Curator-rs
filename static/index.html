    Add sources

    Paste one or more creator URLs, one per line. Works with any site gallery-dl supports — no need to pick a platform first.

    Settings

    Downloading is limited by network requests per source, not by CPU or GPU — so this controls how many sources sync at once, not how fast any single one downloads. Push it higher if your connection and the sites you use can take it; bring it back down if sources start landing on "error" from rate limiting.

    Appearance

    Slideshow defaults

    Applied every time you open the slideshow or portrait wall. Changing the speed/loop/shuffle controls inside a slideshow only affects that session.

    Backup reminders

    The source list is the one thing here that's genuinely hard to recreate if lost — the downloaded files are just a cache. This shows a dismissible sidebar reminder once it's been this many days since your last export.

    Search sites

    Each site needs a search-URL template with {query} where the creator name goes, e.g. https://example.com/search?q={query}. It only works if gallery-dl has an extractor that treats that URL as a listing/search page — test it yourself first: gallery-dl -j "<url with a real name filled in>". If that doesn't print JSON, the template won't work here either.
